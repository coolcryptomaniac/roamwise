# RoamWise Atlas data
All generated by `tools/atlas/*.py` from GeoNames (https://www.geonames.org, CC-BY 4.0) + hand-curated lists. Attribution is required wherever the data is shown.
- `world-countries.json` - 252 countries/territories (tools/atlas/build-world.py).
- `india-admin.json` - 36 states/UTs and ~760 districts (centroids from populated places; curated districts flagged).
- `india-places.json` - ~19k Indian towns, district seats, temples, forts, lakes, peaks, parks; `tools/atlas/india-famous.tsv` (194 hand-curated tourist places) overrides GeoNames.
- `india-namesakes.json` - names shared by 4+ villages in India (e.g. "Rampur" x1012), so Tusk asks "which one?" instead of guessing.
- `world-cities.json` - 34k cities worldwide (pop 15k+) plus ~120 curated landmarks (`tools/atlas/world-famous.tsv`).
Rebuild: download IN.zip, cities15000.zip, admin1CodesASCII.txt, admin2Codes.txt from https://download.geonames.org/export/dump/ then `python3 tools/atlas/build-geo.py SRC_DIR`.
Resolver: `js/data/atlas-resolver.js`; Tusk answers: `js/copilot/atlas-answers.js`. Villages not in the data fall back to the live geocoder.
Uttarakhand's existing deep layer stays in `map/districts.json` + `map/places.json` (partner map).
