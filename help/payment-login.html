RoamWise sign-in & payment self-help

Try these checks before contacting support. They solve most device/browser failures without sharing any private financial information.

Never send support your OTP, UPI PIN, card PIN, CVV, password, recovery code or full card number.
If money was debited, do not pay again until you verify the first transaction status.

1. Sign-in problems

“auth/cancelled-popup-request”
  1. Close any second sign-in popup/tab.
  2. Tap the provider button once and wait.
  3. On Android/iPhone, try the full Chrome/Safari browser instead of an embedded app browser.
  4. Disable strict popup blocking for RoamWise temporarily.
  5. If using the Android app, use Email sign-in when social login is unavailable in the WebView.
Google/Facebook/Apple does not open
  • Turn off VPN/private DNS/ad blockers temporarily.
  • Allow cookies and popups for roamwise.co.in.
  • Use a normal browser tab, not Instagram/Facebook/WhatsApp in-app browsers.
  • Safari: disable “Block All Cookies”; Brave: lower Shields for the sign-in attempt.
  • Update Chrome/WebView on Android and Safari/iOS on iPhone/iPad.

2. Payment button does nothing

  • Android app/WebView: RoamWise opens a secure browser handoff so UPI apps can receive the intent correctly.
  • Android browser: make sure GPay/PhonePe/Paytm/BHIM is installed and updated.
  • Desktop: use QR/copy UPI or the available card/international checkout.
  • iPhone/iPad: UPI deep links depend on an installed compatible app; use the browser handoff or card checkout when needed.
  • Google Play build: digital Pro purchase must use Google Play Billing when that build enables it.

3. Bank/card/UPI failure

  1. Check balance/credit limit and daily UPI/card limits.
  2. Confirm online/international/e-commerce transactions are enabled where required.
  3. Complete bank 3DS/OTP in the bank page; do not switch apps repeatedly during authentication.
  4. If issuer declines the payment, try another supported bank/payment method.
  5. UPI can be India-only; international users need an enabled international checkout provider.

4. Browser/device reset checklist

  • Reload the page and retry once.
  • Open an Incognito/Private tab.
  • Clear RoamWise site data/cache only.
  • Update browser + OS.
  • Set date/time to automatic.
  • Try Wi-Fi ↔ mobile data.
  • Disable VPN, ad-blocking, script-blocking or aggressive privacy protection for one test.
  • Try Chrome/Firefox/Edge/Safari on the same device.

5. Compatibility scope

RoamWise is designed for current Chrome, Edge, Firefox, Safari, Brave, Opera, Kiwi-class Chromium browsers, Android WebView/native wrapper, installed PWA, Windows, macOS, Linux, Android and iOS. Payment availability still depends on the user's country, bank, issuer, UPI app, merchant account and payment-provider coverage.
