# Ailon experience and agent commerce roadmap

## Dual hosting decision
roamwise.co.in: GitHub Pages primary (unchanged until founder moves DNS). roamwise.tech: Cloudflare Pages project roamwise-web. Add custom domain through Pages, verify TLS, then add exact authorized origins to Firebase Auth, Worker CORS, Cashfree and OAuth redirect settings. Keep worker API and assets origin explicit. Do not move DNS, authorize new payment origins or switch canonical SEO without verified deployment. Local storage/BYOK keys and browser sessions are origin-separated; never copy credentials silently. No token or secret in public repo.

## Media and discovery
Use the progressive rail with curated atlas; geographic index is not guide quality. R2 media assets: image variants, clips, artwork, licensed audio, provenance, checksums, attribution, alt text. No autoplay; no generated image pretending to be a real place. Bounded manifest, cache public content only; authenticated or live booking info remains uncached. Future API pagination, virtualized rails and asset ingestion are tracked separately. Rave, Odyssey and Aipan moods are CSS; new artwork must be rights-cleared. Measure device performance before claiming wins.

## Agent Commerce / Journey Mission Exchange (proposal)
Travelers define a mission (dates, total budget, preferences); opt-in supplier agents submit itemized quotes for accommodation, guides, local artists, transport, weddings and experiences. Ailon validates compatibility, produces a single itemized plan and asks user to explicitly approve before authorized PSP checkout. Supplier agents can purchase narrowly scoped verified itinerary data or API tasks through metered prepaid B2B credits, subject to terms and accounting. No self-issued money, no custody or cross-agent transfer of balances, no speculative tokens or automatic payment. Payment authorization, price, vendor, expiry, refund and audit ledger must be bound and revalidated; idempotency and webhook reconciliation. AP2/A2A and x402 are research compatibility candidates, not production support. MVP: human-approved enquiries and existing Cashfree checkout only. India legal/PSP review before any delegated spend or prepaid payment product. No claim of world-first uniqueness.

## Provider cost routing
Local deterministic knowledge -> indexed D1 -> reviewed cached public response -> cheap hosted reasoning for complex tasks if entitled -> explicit BYOK provider choice. Meter per request/tenant/provider, token cap and circuit breaker, fallback only to user-authorized paid provider. No provider secrets in URLs or logs, no background billable calls. Existing optional provider settings remain opt-in. Evaluate real quality, latency and cost by route. Provider configuration, cross-origin deployment, R2 uploads, and agent payment implementation are not part of this PR.
