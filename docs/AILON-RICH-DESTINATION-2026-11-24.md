# Rich destination cards and direct booking
The browser bundles 354 destination profiles: 184 India and 170 international. New world entries and Goa/Coorg itineraries are editorial drafts, not supplier inventory. Goa reference: https://goa-tourism.com/popular-destination/ ; Coorg reference: https://karnatakatourism.org/en/destinations/coorg/ . Rebuild the browser catalogue using node knowledge/tools/build-browser-atlas.mjs and verify with node knowledge/tools/build-browser-atlas.mjs --check.
Simple destination requests can render without hosted AI. Existing specialist flows and the Manali/Corbett/Gir first-party offers hook keep precedence. The local atlas fallback covers safe planning requests when AI is unavailable, with a three-day draft rather than implying a custom itinerary for every duration. Live weather, transport, account support, and emergency questions remain on their existing routes. All booking prices come from the existing catalogue, then server quote and explicit user payment consent. No matching listing means enquiry only, no fabricated price or payment button. No new supplier contracts or listings are created.
