# Ailon Tusk embed (website)
Include <script defer src="https://www.roamwise.co.in/embed/ailon-tusk.js"></script> and <div data-ailon-tusk data-category="shop"></div>. The script uses a Shadow DOM for style isolation. Category options: shop, stays, packages, treks, pro, music. It only navigates to RoamWise-owned pages; no payment is initiated in the host website. Host applications can use a WebView to render the widget subject to their platform policies.
Security: no API keys, cookies, payment tokens, customer identity, card fields or direct UPI intent handling. Payment requires an explicit customer checkout action and server-verified Cashfree/UPI status. Never trust AI-generated totals. A seamless one-tap payment would require a customer-selected verified SKU, validated delivery details, authenticated checkout creation, explicit payment approval, payment-provider SDK handoff, webhook verification, and idempotent fulfillment. Those steps are NOT implemented by this widget.
The minimal /tusk/mcp JSON-RPC endpoint is separately available for third-party AI discovery, but this is NOT a registered ChatGPT app. Validate MCP compatibility, production host, authentication, rate limiting, consent, and OpenAI app review before claiming ChatGPT installation.
