How to claim, in 5 steps

  1. Get your personal pass code from E-Cell. It looks like NMIMS-STU-0123-XXXXXXXXXXXXX. Each code is single-use. A poster QR only opens the redeem form and never gives you a pass, so ask your E-Cell coordinator.
  2. Open RoamWise at roamwise.co.in in Chrome or Safari (or the app).
  3. Sign in with Google or email, and verify your email. The code only works on a verified account.
  4. Tap "I have a pass → Redeem" on the home page. You can also open the menu and choose Redeem code.
  5. Paste your code. A congratulations card appears and Founder Pro turns on for life.

Good to know

  • One code per person. If your account already has Pro, the code is not used. Give it to a friend instead.
  • Redeem within 30 days of the day E-Cell issued it. After that it expires. Pro you have already activated stays.
  • Passes can't be bought, sold or swapped. A lost card can be cancelled by E-Cell and replaced.
  • Travel-safety and survival tools stay free for everyone. You never need a pass for those.
  • Got no pass? Founder Pro is ₹100 for life for the first 1,000 Pro members, then standard prices apply. If you buy, enter NMIMS2026 as the referral code so E-Cell NMIMS is credited. It does not change your price.
